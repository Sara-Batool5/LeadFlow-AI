# LeadFlow AI — Phase 1 UI Fix

This update improves contrast and styling in the Phase 1 Streamlit application.

## Changes
- Brighter text on the dark navy/purple background.
- Dark input fields with visible borders.
- Improved table styling and contrast.
- Styling for the Streamlit header area to reduce the bright white top strip.
- No changes to application workflow or logic.

## Upload instructions
Upload `app.py`, `requirements.txt`, and `README.md` to the root of the existing `leadflow-ai` GitHub repository, replacing the existing files when prompted.

The `.gitignore` file is intentionally not included because GitHub’s web uploader may hide dotfiles. It is optional for this phase and is not required for deployment.
